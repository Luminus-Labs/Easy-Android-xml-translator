Workflow

The app works in two steps: first generate a translator link, then open that link to translate the XML in the browser. The link carries parameters so the translator mode knows what to load.

Link Generator Help

Provide the base English strings.xml URL and target language. The tool automatically guesses the translated file location and generates a translator link.

How it flows

  1. Paste the raw English strings.xml URL.
  2. Choose the target language.
  3. Generate the translator link.
  4. Open the link in translator mode.
  5. Edit translations directly and keep working from the same page.
