Workflow

The app works in two steps: first generate a translator link, then open that link to translate the XML in the browser. The link carries the source file, target file, and language so the translator mode knows what to load.

How it flows

  1. Paste the raw English strings.xml URL.
  2. Choose the target language.
  3. Generate the translator link.
  4. Open the link in translator mode.
  5. Edit translations directly and keep working from the same page.

About

Lightweight and free web tool to let human contributors translate Android strings.xml files for you. You will get the translated xml file via email or github issues. No account or configuration required, just a link containing all the info.
